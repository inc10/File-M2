# GenOffice Linux ARM64 build

This repository contains a GitHub Actions workflow that builds the upstream
[g enspark-ai/genoffice](https://github.com/genspark-ai/genoffice) source on a
native Ubuntu ARM64 runner. It does not modify the upstream repository.

Open the **Actions** tab and run **Build GenOffice Linux ARM64**. The resulting
Linux packages are published as the workflow artifact `genoffice-linux-arm64`.
